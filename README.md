# Практика 1 / Задание 1 / Варианты 1–2

Отдельный проект C++17 для Qt Creator (Qt 5 или Qt 6, модули Core, Widgets,
3DCore, 3DRender, 3DExtras, 3DInput; для тестов также Test).
Рекомендуется комплект Qt 6. Все модули Qt должны быть одной совместимой версии.
Класс `Drone` разделён на `drone.h` и `drone.cpp`.

- Вариант 1: взлёт, посадка, движение, изменение заряда, вывод состояния,
  аварийная посадка.
- Вариант 2: обновление и проверка телеметрии.

Взлёт требует заряда не менее 10%, движение — не менее 5%; каждое успешное
действие расходует 1%. Аварийная посадка всегда сбрасывает высоту и состояние
полёта. Координаты должны быть конечными числами, высота — неотрицательной.
Конечное значение заряда ограничивается диапазоном 0–100%; NaN и бесконечность
отклоняются. Ошибочное обновление телеметрии сохраняет предыдущие данные.
Идентификатор считается корректным при `id >= 0` (0 — значение по умолчанию
из задания). Обновление телеметрии не меняет флаг полёта: им управляют методы
взлёта и посадки.

Откройте `CMakeLists.txt` в Qt Creator, выберите комплект Qt и запустите
`Practical_01_Task_1`. Откроется небольшое окно с координатами, зарядом,
кнопками взлёта, посадки, перемещения и обновления телеметрии. Текущее состояние
и результат действия отображаются в окне. Поля ввода ограничивают допустимые
значения; для проверки отказа во взлёте установите заряд ниже 10%.

Интерфейс создаётся стандартными виджетами Qt в `mainwindow.cpp`.
Консольные примеры сохранены в `demo.cpp` и запускаются целью `drone_demo`.

Справа отображается 3D-среда, адаптированная из
`Practical_03_Classes/ew_route_3d`: площадка 600 × 400 м, сетка с шагом 50 м,
цветные оси, жёлтая сфера в точке (300, 200, 200) радиусом 120 м и картинка БПЛА.
Геометрия, камера и `DroneVisual` перенесены в этот проект; изображение встроено
через `assets.qrc`, поэтому исходный каталог для сборки и запуска не нужен.

Красный куб показывает координаты из полей ввода, зелёный — начало координат.
Взлёт, перемещение, посадка и обновление телеметрии сразу обновляют положение
БПЛА в сцене. Состояние хранится в прежнем классе `Drone`; жёлтая сфера служит
ориентиром, автоматический обход препятствий не выполняется. Картинка БПЛА
поднята на 15 м над точкой координат для видимости на земле; это не меняет
показания высоты. Координаты вне площадки также допустимы.

Управление камерой: ПКМ с движением — вращение, ЛКМ — сдвиг, колесо и кнопки
«Приблизить»/«Отдалить» — масштаб. «К БПЛА» показывает текущую позицию крупнее,
в том числе вне площадки; «Общий вид» восстанавливает исходную камеру.

Из каталога этого проекта:

```sh
cmake -S . -B build
cmake --build build
./build/Practical_01_Task_1
./build/drone_demo
ctest --test-dir build --output-on-failure
```

Для сборки без тестов укажите `-DBUILD_TESTING=OFF`. Тесты проверяют модель,
синхронизацию 3D-позиции с кнопками, предпросмотр цели, камеру и встроенный ресурс.
На Linux с рабочим столом можно сохранить снимок реального рендера:

```sh
QT_QPA_PLATFORM=xcb UAV_SCREENSHOT=/tmp/uav_sim1.png ./build/window_tests
```
